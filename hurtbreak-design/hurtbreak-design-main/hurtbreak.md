# Abstract
`hurtbreak` will be a mutational and random state fuzzing library, with unified tracing and seeding. Eventual AI orchestration for hopefully automated low skill pentesting.
# Goals
- Unified seed format, reproducibility
	- `.hurt` spec perhaps?
- Learn how mutational fuzzers actually work
- Control flow detection via a tripwire spec
	- File overlay ontop of `.hurt`
- Python bindings
